MARQEE

Privacy Policy — RSS Ticker Extension

Effective: 2026-09-03 Applies to: MarQee — RSS Ticker v1.0.1+ Platform: Google Chrome
In short: MarQee runs entirely inside your browser. The feeds you add and the settings you choose are saved with Chrome's built-in storage.local API on your own device — MarQee has no server of its own, so there is nowhere for that data to go. The only network traffic MarQee causes is your browser fetching the RSS feeds you configured, directly from the sites that publish them.

What MarQee stores

DataWhere it livesWhy
RSS feed list chrome.storage.local Remembers the feeds you've added so the ticker can keep pulling headlines from them.
Ticker settings chrome.storage.local Position, scroll speed, colors, effects, filters — everything on the Settings tabs.
Fetched headlines In-memory cache (1h) Short-lived copy of each feed's latest items, so the ticker doesn't refetch on every page load.

None of this leaves your device. Uninstalling MarQee, or clearing the extension's storage in Chrome, deletes it permanently. Exporting a backup from the Backup tab writes a plain JSON file to your own computer — MarQee never uploads it anywhere.

What MarQee does not do

  • It does not operate a server, database, or API — there is no back end to send your data to.
  • It does not use analytics, advertising SDKs, or third-party trackers of any kind.
  • It does not read, log, or transmit the content of the pages you browse.
  • It does not require an account, email address, or any personal identifier.
  • It does not sell or share data, because it never collects any to begin with.

Network requests

When the ticker refreshes, your browser makes a direct HTTPS request to the feed URL you configured — the same request your browser would make if you visited that URL yourself. MarQee's defaults are BBC World, TechCrunch, and NASA Breaking News; anything beyond that is a feed you chose to add. Those requests are governed by each publisher's own privacy policy, not MarQee's.

Permissions, and why they're requested

PermissionUsed for
storage Saving your feed list and settings locally, as described above.
activeTab Detecting whether the page you're currently viewing publishes an RSS feed, to power the "Quick Add" banner. MarQee only looks at feed links — it doesn't read the rest of the page.
alarms Waking the extension on a schedule to refresh your feeds at the interval you set.
Host access (all sites) Drawing the ticker bar itself, since you can choose to show it on any site you visit. The content script only adds the ticker overlay — it does not collect anything from the host page.

Children's privacy

MarQee is not directed at children and does not knowingly collect information from anyone, including children under 13 — it does not collect personal information from any user, of any age.

Changes to this policy

If MarQee's data practices change, this page will be updated and the effective date above will change with it. Continued use of the extension after an update means you accept the revised policy.
